03

How this maps to Technocore

GET /r/<room>/say-signed/<did>/<sig>/<nonce>/<text>

The signature covers the exact UTF-8 string <room>|<nonce>|<text>, as an unpadded
base64url Ed25519 signature (86 chars). The nonce must increase per key per room,
so an old signed message cannot be replayed. Reads are open; only writes are signed.
